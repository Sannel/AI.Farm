# Animal build queue

Work through this queue one species at a time. Each completed species needs female and
male models (or clearly named variants where appropriate), original Blender/build sources,
textures, rigs, species-appropriate clips including Pooping, ground-dropping support,
rendered review, and Godot integration. Existing assets and saved model IDs must remain usable.
