# Animal droppings

Original AI Farm models, generated by `build_droppings.py`; no third-party assets.

| Asset | Animals |
| --- | --- |
| Cow_Pat | Cows |
| Pig_Pile | Pigs |
| Pellets | Goats and sheep |
| Horse_Pile | Horses and donkeys |
| Dog_Pile | Dogs |
| Chicken_Dropping | Chickens (brown dropping with pale urate cap) |

Rebuild with Blender:

```sh
blender -b --python-exit-code 1 --python src/Client/ai-farm/assets/Droppings/build_droppings.py -- /tmp/droppings
```

Each GLB is a static mesh with matte embedded materials and a ground-level origin.
The original `.blend` files remain editable. Units are metres; exports use Godot Y-up.

Every animal has a one-shot `Pooping` animation. Aim at an animal, open its animation
menu with the action button, and choose `Pooping`. `CharacterAnimator` deposits one
species-appropriate prop halfway through the animation. Props follow terrain slope,
remain when the animal moves or is removed, and belong to the `animal_droppings` group.
Repeating the animation deposits another prop; cancelling before halfway deposits none.

Droppings currently last for the current client scene. They are visual props without
collision, automatic timers, database persistence, or multiplayer synchronization.

Validate in the Godot .NET project after building/importing:

```sh
dotnet build 'src/Client/ai-farm/AI Farm.csproj'
godot --headless --path src/Client/ai-farm --script res://tools/verify_droppings.gd
```
